SENZANY MAP V10.5

CORRECTIONS :
1. Le panneau admin est MASQUE par défaut.
   Seul un bouton "OUTILS ADMIN" apparaît en haut à droite.
   Le panneau s'ouvre uniquement au clic et peut être refermé.

2. Le bloc de DEMANDE JOUEUR est restauré.
   Aucun texte de développement n'est affiché.
   Les coordonnées X/Z ne sont jamais montrées au joueur.

3. Le joueur clique "DEMANDER UN EMPLACEMENT",
   choisit sur la carte, saisit un nom/commentaire et envoie.

INSTALLATION :
- Remplacer senzany-map.html
- Remplacer senzany-admin-map.html
- Ajouter map/index_carte_senzany_v10_5.html
- Remplacer backend/server.js
- Ajouter backend/routes/mapRequests.js
- Exécuter supabase/026_map_requests.sql dans Supabase
- Commit / Push / git pull
- pm2 restart senzany-api --update-env
